## 판단하지 말고 남길 것

원음을 들어야 확정되는 고유명사·수치는 **고치지 말고 사용자에게 목록으로 보고**한다.
추측 치환은 자막을 더 나쁘게 만든다.

실제 미해결 사례(2026-08-03):
`4랜드` · `10년 후짜리` · `볼타`(세금계산서 API 서비스명) · `몇 시번`(건당 단가) ·
`리러 오피스`(부산 공간명) · `상세, 레어` · `한국에 들어가는` · `나의 제목`

## 적용 시 주의

- `노선`→`노션` 같은 짧은 치환은 **오적용 위험**이 있다. 해당 영상 맥락에서 항상 노션을 뜻하는지 먼저 확인.
- `사스`→`SaaS`는 `사스에 있는`/`사스가 너무`처럼 **조사까지 포함해** 규칙을 쓰면 안전하다.
- 치환 건수를 항상 로그로 남기고 사용자에게 종별로 보고한다.
