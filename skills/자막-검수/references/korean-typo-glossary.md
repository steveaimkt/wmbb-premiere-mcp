## 판단하지 말고 남길 것

원음을 들어야 확정되는 고유명사·수치는 **고치지 말고 사용자에게 목록으로 보고**한다.
추측 치환은 자막을 더 나쁘게 만든다.

실제 미해결 사례(2026-08-03):
`4랜드` · `10년 후짜리` · `볼타`(세금계산서 API 서비스명) · `몇 시번`(건당 단가) ·
`리러 오피스`(부산 공간명) · `상세, 레어` · `한국에 들어가는` · `나의 제목`

## 적용 시 주의

- `노선`→`노션` 같은 짧은 치환은 **오적용 위험**이 있다. 해당 영상 맥락에서 항상 노션을 뜻하는지 먼저 확인.
- `사스`→`SaaS`는 `사스에 있는`/`사스가 너무`처럼 **조사까지 포함해** 규칙을 쓰면 안전하다.
- 치환 건수를 항상 로그로 남기고 사용자에게 종별로 보고한다.
- **한 토큰에 규칙이 순서대로 연쇄 적용된다.** `맛없는→여기까지밖에` 뒤에 `밖에→(삭제)`를 두면 방금 만든 "밖에"도 지운다. `환자→환자분은` 뒤 `분은→(삭제)`도 같은 사고(실측 2건). 삭제 규칙을 먼저 두고, 대체어가 다른 규칙의 대상 문자열을 포함하지 않게 쓴다.
- `것들`·`밖에`처럼 짧은 문자열의 삭제·치환은 **문장 ID로 범위를 묶는다**(프로젝트 사전 `[잘못, 올바름, 문장ID]`). 범위 없이 쓰면 "이것들이", "그런 것들을"이 망가진다.
- 전사가 통째로 깨진 문장(실측: "엉덩이만 안타깝지만 맛없는 것들 밖에")은 사전으로 고치지 말고 그 구간만 slice ASR로 다시 들려 후보를 얻는다. 두 판독이 다르면 확실한 부분만 고치고 나머지는 사용자 확인 목록으로.
