# 자막 검수 (편집본 기준)

**편집이 끝난(또는 편집 중간의) 타임라인을 읽어 자막을 만든다.** 컷편집과 독립적으로 단독 실행할 수 있다 — 사용자가 프리미어에서 직접 편집한 뒤 불러도 된다.

**트리거 "자막 검수 시작하자" → STEP A부터.** 각 STEP 끝에서 멈추지는 않되, **STEP A 검증에 실패하면 반드시 멈춘다.**

---

## 원칙 — 재전사하지 않는다

원본을 **한 번만** 전사하고, 그 워드 타임스탬프를 편집본 타임라인으로 **재투영**한다.
편집을 몇 번 반복하든 이 방식이면 프리미어 실측과 **프레임 단위로 일치**한다.

재전사가 나쁜 이유(실측):
- 품질이 오히려 하락 — 이미 고쳐놓은 용어가 엉뚱한 말로 되돌아가고, 브랜드명이 띄어쓰기로 쪼개지고, 문장이 `"…된다."`처럼 중간에서 끊김
- 20분 재전사에 수 분 소요
- 손으로 쌓은 오탈자 교정이 전부 날아감

## STEP A — 타임라인 매핑 재구성 ★ (실패하면 여기서 멈춤)

```
list_sequence_tracks(sequenceId, includeSourceTimes: true)
```
클립마다 `startTime`/`endTime`(타임라인)과 `inPoint`/`outPoint`(소스)가 함께 온다.
**이 한 콜이 source→timeline 맵 전체다.**

```python
FPS = 24
NEW = []; acc = 0
for c in v1_clips:                                   # 타임라인 순서
    a, b = round(c['inPoint']*FPS), round(c['outPoint']*FPS)
    NEW.append((a, b, acc)); acc += b - a
assert abs(acc/FPS - verify['measuredEndSec']) < 1e-4   # ← 통과 못 하면 중단
```

**길이 판정은 `verify.measuredEndSec`로 한다.** `list_sequences`의 `duration`은 편집 중 과도 상태를 반환한다(1352.75 → 1310.21 → 1279.67로 요동친 실측 있음).

`verify`에서 함께 확인:

| 필드 | 기대 | 아니면 |
|---|---|---|
| `contiguous` / `gapCount` | `true` / `0` | 타임라인에 구멍 — 자막을 만들지 말고 보고 |
| `avParity` | `true` | V/A 클립 수·끝이 다름 — 싱크 확인 요청 |
| `durationMatchesClips` | `true` | 프리미어가 아직 갱신 중일 수 있음. 한 번 더 읽어본다 |

> ⚠️ **사용자가 프리미어에서 동시 편집 중일 수 있다.** 값이 이상하면 **한 번 더 읽고** 판단한다. 편집 중 판독으로 "타임라인 손상"을 오보한 사례가 있다.

> 클립이 수백 개면 `compact:true`로 `verify`만 먼저 보고, 필요할 때 전체를 읽는다.

## STEP B — 전사 확보

이미 `analyze_speech_edit_points` 결과(`analysis.json`)가 있으면 **그대로 쓴다.**

없을 때만 1회 전사:
```bash
ffmpeg -y -i "<mediaPath>" -map 0:a -c:a pcm_s16le -ar 16000 -ac 1 cut.wav
```
```
analyze_speech_edit_points(filePath: cut.wav, language:"ko", model:"small")
```
- **`model`은 `small` 이상.** `base`는 한국어 오프닝을 통째로 놓친다.
- 응답이 파일로 떨어지면 python 파싱. **이중 인코딩 JSON일 수 있다** — `json.loads(json.loads(raw))`.

## STEP C — 큐 조립

전체 절차·코드 → **`references/subtitle-pipeline.md`**

핵심 규격(steve 채널 표준):

| 항목 | 값 |
|---|---|
| 줄 수 | **1줄** (여러 줄 금지) |
| 글자수 | **최대 20자** |
| 큐 사이 공백 | **0.0000초** (끝 = 다음 시작) |
| 노출 | 평균 2초 내외, 최소 0.7초 지향 |

**문장이 잘리지 않게** — 사전 2개로 원자를 먼저 묶고 나서 자른다:
```python
NO_START = ("라고","라는","하면","하고","해서","되니까","때문에","는데","지만",
            "거든요","잖아요","습니다","거죠", ...)   # 큐를 시작할 수 없는 말
NO_END   = {"그","저","좀","뭐","이제","그리고","그래서","근데","사실","예를", ...}  # 큐를 끝낼 수 없는 말
```
투영 시 두 함정을 막는다 — **경계 유령 자막**(겹침 0.35초/40% 미만 버림), **중복 출력**(인접 클러스터 병합). 단 콜드오픈처럼 같은 소스가 두 곳에 쓰이면 클러스터가 갈리는 게 정상이고 각각 자막을 낸다.

## STEP D — 오탈자 교정

사전 → **`references/korean-typo-glossary.md`** (현재 76종)

**토큰 단위 1회 + 큐 병합 후 1회, 두 번 돌린다.**
> 병합 전에는 `"필히"`+`"이 거래명세서에서"`가 따로라 `"필이 이"` 규칙이 안 걸리고,
> 병합 후에는 줄바꿈이 끼어 `"바이브 코딩라면"`이 안 걸린다.

**판단 불가한 건 고치지 않는다.** 고유명사·수치는 추측 치환하면 더 나빠진다.
목록으로 뽑아 사용자에게 확인받는다(실측 미해결: `볼타` `리러 오피스` `4랜드` `몇 시번` 등).

교정 건수를 **종별로 로그**해서 보고한다.

## STEP E — QC (전부 0이어야 통과)

```
겹침 · 역순 · 길이0 · 시퀀스 초과 · 큐 사이 공백 · 여러 줄 큐 · 20자 초과 · 잔여 오탈자
```
마지막 큐 종료 ≤ `verify.measuredEndSec` 확인.

**주요 이음새 육안 검증** — 컷 지점 전후 자막을 뽑아 말이 자연스럽게 붙는지 본다:
```
"…그게 그러진 않더라고요 / 그렇죠 마지막으로 / 두 가지만 좀 여쭤보고 싶은데"   ✅
```

## STEP F — 내용·흐름 리뷰 (요청 시)

자막 전문을 40초 블록으로 압축해 통독한 뒤 **채널 원칙(`CLAUDE.md` §1.5)**과 대조한다.

기계적으로 먼저 grep:
```
접근성 신호 : 비개발자 · 개발지식 · 코딩 몰라도 · 왕초보
CTA        : 구독 · 좋아요 · 댓글 · 링크 · 신청
리캡        : 정리하면 · 첫번째/두번째 · 요약
```
**0건이면 그 자체가 지적 사항이다.** 실측: 세 항목이 한꺼번에 0건이던 사례.

리포트는 **우선순위 + 타임코드 + 처방**. 잘라낸 구간에 해답이 있으면 복원 좌표(소스 TC)를 준다.

## 자막 파일 저장

- 경로: 프로젝트 `.prproj`와 **같은 폴더**
- 이름: `<프로젝트명>_최종_<길이>.srt` (예: `260802 인터뷰_최종_21m20s.srt`)
- **이전 버전은 지운다.** 길이가 다른 자막이 여러 개 있으면 사고 난다.
- 저장 후 경로를 보고하고, 요청 시 `open -R`로 Finder에 띄운다.

### 프리미어 캡션 트랙으로 넣기
`export_captions(importToSequence)`가 예전엔 `Illegal Parameter type`으로 항상 실패했다(2026-08-03 MCP에서 수정). **수정본이 실기 검증되기 전까지는** 실패를 전제하고, 사용자에게 안내한다:
> 프리미어 `파일 › 가져오기`로 SRT를 불러온 뒤 프로젝트 패널에서 타임라인으로 드래그

유튜브 업로드용이면 파일 그대로 올리면 된다.

## 자주 하는 실수

- **매핑 합계 검증을 건너뛰면** 조용히 어긋난 자막이 나온다. 반드시 assert.
- **`list_sequences.duration`으로 판정하면** 편집 중 값에 속는다.
- **타임코드↔초 변환을 암산하면 틀린다.** `83:03`을 `5043`으로 계산한 실수가 실제로 났다(`83*60+3=4983`). 반드시 코드로.
- **시퀀스가 여러 개면 대상을 ID로 특정한다.** 백업이 쌓이면 전부 `시퀀스 01 복사`가 된다.
